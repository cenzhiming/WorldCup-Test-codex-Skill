# 2026 世界杯赛制与赛区参考

> 本文件为 2026 美加墨世界杯的赛制、晋级规则、赛区气候与时区参考，供预测与推演时调用。
> ⚠️ 赛制/规则类信息**须以 FIFA 官方当届公布为准**（不同届可能微调）；地理/气候为相对稳定事实，但具体场馆条件仍建议赛前核验。

---

## 一、基本赛制

| 项目 | 内容 |
|------|------|
| 参赛队 | 48 队（史上首次） |
| 分组 | 12 组（A–L），每组 4 队 |
| 小组赛 | 单循环，每队 3 场 |
| 晋级 | 每组**前 2 名**直接晋级 + **8 个成绩最好的第三名** → 32 强（Round of 32） |
| 淘汰赛 | 32 强 → 16 强 → 8 强 → 半决赛 → 决赛，单场决胜（平则加时/点球） |
| 东道主 | 美国、加拿大、墨西哥 |
| 时间 | 2026-06-11 至 2026-07-19（约 39 天，104 场） |

## 二、小组同分排名规则（标准顺序）

两队或多队积分相同时，依次比较：

| 优先级 | 规则 |
|--------|------|
| 1 | 积分（胜 3 / 平 1 / 负 0） |
| 2 | 总净胜球 |
| 3 | 总进球数 |
| 4 | 相互战绩积分 |
| 5 | 相互战绩净胜球 |
| 6 | 相互战绩进球数 |
| 7 | 公平竞赛积分（红黄牌罚分） |
| 8 | FIFA 抽签 |

> ⚠️ `group_sim.py` 目前只实现了 1–3（积分/净胜球/进球数）并对相互战绩做了简化，三队同分的复杂情形须人工按上表逐条复核。

---

## 三、"最佳第三名"晋级判定（跨组）

12 个小组的第三名按以下顺序排序，取**前 8 名**晋级 32 强：

1. 积分 → 2. 净胜球 → 3. 进球数 → 4. 公平竞赛积分 → 5. 抽签

**分析要点**：
- 第三名出线门槛通常为 **3–4 分**（历史 32 队时代 16 强赛制下约 4 分稳出线；48 队新制阈值须看实际分布，建议用当届实时数据校准）。
- 推演单组时，第三名"是否出线"无法在组内确定，必须跨组横向比较 → 这是 `group_sim.py` 不计算、需人工汇总 12 组第三名后判断的部分。

## 五、时区与"今晚"歧义（强制标注）

东道主横跨多个北美时区，对中文用户极易产生"今晚/明天"误判。**预测前必须确认并同时标注当地时间与北京时间**。

| 北美时区 | 与北京时差（夏令时） | 典型城市 |
|----------|---------------------|----------|
| 东部 ET（EDT, UTC−4） | 北京 = ET + 12h | 纽约、波士顿、费城、亚特兰大、迈阿密、多伦多 |
| 中部 CT（CDT, UTC−5） | 北京 = CT + 13h | 达拉斯、休斯顿、堪萨斯城、墨西哥城* |
| 山地 MT（MDT, UTC−6） | 北京 = MT + 14h | （视赛区） |
| 太平洋 PT（PDT, UTC−7） | 北京 = PT + 15h | 洛杉矶、湾区、西雅图、温哥华 |

\* 墨西哥城时区/夏令时政策与美国不同，须单独核验。

**实操规则**：
- 美东下午/晚场（ET 15:00–21:00）对应**北京次日凌晨 03:00–09:00**——中文语境的"今晚熬夜场"通常指这批。
- 输出赛程/预测时一律写成「当地 HH:MM ET/CT/PT（北京 次日 HH:MM）」，避免"今晚 4 场"指代不清。
- 遇到用户说"今晚/明天"而对阵未明确时，先列候选赛程并按北京时间确认，再开始预测（见 SKILL.md §4 Step 3）。
